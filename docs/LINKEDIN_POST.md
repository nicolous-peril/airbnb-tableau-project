# LinkedIn Post Draft

I recently completed a Tableau dashboard project analyzing Seattle Airbnb data.

This was a guided portfolio project based on Alex The Analyst's Tableau beginner project, and I used it to practice the full dashboard-building workflow: connecting Excel data, validating joins, choosing the right aggregations, creating multiple visualizations, and publishing the final dashboard to Tableau Public.

The dashboard explores:

- Average price by zip code
- Geographic pricing patterns across Seattle
- Revenue trends throughout the year
- Average price by bedroom count
- Listing competition by bedroom category

One key takeaway was how important it is to understand the data model before building visuals. For example, the dataset includes multiple ID fields, but not all of them represent the same business entity. Joining on the wrong ID would create misleading results.

This project helped me strengthen my Tableau, data visualization, and business intelligence skills while learning how to turn raw data into an interactive dashboard.
